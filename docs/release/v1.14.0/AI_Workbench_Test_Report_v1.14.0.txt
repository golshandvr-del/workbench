Not performed / release limits
------------------------------
- Native Windows 10/11 double-click installation, upgrade, uninstall, shortcut and pythonw launch: NOT RUN.
- Real LTspice simulation: NOT RUN.
- Static dependency and non-Python source-language semantic analysis are heuristic, bounded,
  advisory analyses; they do not replace a compiler, linker, runtime test, or simulator.
- YAML-aware semantic parsing is not included. JSON structural parsing and CSV keyed-row/cell
  comparison are included. Regex-based source-language diffs may miss body-level changes.
- The application remains a modular monolith at the UI/orchestration boundary: AI_Workbench.py
  is still the stable entry point, while new domain services are in aiwb/.
