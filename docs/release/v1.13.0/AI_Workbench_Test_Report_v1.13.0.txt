Important limitations
---------------------
- Context ignore handling is a conservative subset, not full Git-ignore compatibility.
- A successful process exit is process evidence, not domain correctness; manual validation steps remain Not run.
- Diagnostics export is local-only and omits source, prompts, responses, command text, process output and full project paths by default, but redaction is not a mathematical guarantee that all sensitive values are absent.
- The roadmap items not implemented in this release are explicitly listed in CHANGELOG.md: typed Delete/Rename/Move, full architecture-plan round-trip UI, multi-candidate response comparison, task playbooks, change-impact analysis, semantic structured-file diff, and static dependency adapters beyond the current conservative context heuristics.
